# 03 - 畫面佈局與 UI/UX 互動規範

> **目標**：規範 Fred's POS 前端 3 大核心視圖的介面版型、暗色系科技感視覺規範、觸控與鍵盤人體工學，以及細節互動流程。

---

## 1. 視覺設計系統 (Dark Tech Design System)

模型車實體店兼具專業收藏與高單價特性，視覺風格採用**暗色系現代科技感 (Dark Mode Modern Tech)**：

### 1.1 色彩代碼規範 (Tailwind CSS Tokens)
- **背景層級 (Backgrounds)**：
  - 主基底底色：`bg-zinc-950` / `bg-slate-950`
  - 卡片與面板底色：`bg-zinc-900` / `bg-slate-900`
  - 懸浮與啟用狀態：`bg-zinc-800` / `bg-slate-800`
  - 邊框線條：`border-zinc-800` 或 `border-zinc-700/50`
- **強調色與功能色 (Accents & Status)**：
  - **主操作與聚焦**：`cyan-400` / `cyan-500`（按鈕、選中外框、主要數值）
  - **成功與現貨**：`emerald-400` / `emerald-500`（在庫數量正常、結帳成功）
  - **預訂與警示**：`amber-400` / `amber-500`（預購單標籤、庫存偏低、手動改價標籤）
  - **危險與刪除**：`rose-500` / `red-500`（刪除品項、負數退貨折抵、作廢）
- **文字與數值排版**：
  - 標題與標籤：清晰無襯線字體 (`font-sans font-medium text-zinc-200`)
  - 金額、數量、條碼、貨號：**一律採用等寬數字字體** (`font-mono font-semibold tracking-wide`)

## 2. 系統入口與視圖導覽 (System Landing & Navigation)

### 2.0 系統初始狀態 (Landing Welcome Screen)
- **首次進入頁面時**：系統預設不主動展示特定的業務畫面（不載入商品列表與結帳單），左側導覽欄保持預設展開狀態，主區域呈現清爽專業的 **FRED'S POS 歡迎引導畫面**。
- 畫面中央清楚提示使用者點選左側導覽列展開指定作業（出單結帳、商品庫存、客戶會員），亦提供大按鍵快捷入口。
- **點擊任一功能（無論是點擊首頁大按鈕或左側導覽列）**：系統皆會**自動平滑收折左側導覽列**為緊湊圖示模式（64px），立即為進入的功能畫面釋放最大作業寬度。
- 店員亦可隨時點擊頂部導覽列左側 **`FRED'S POS`** Logo 返回此歡迎主選單（返回主選單時導覽欄自動復原展開）。

### 3.1 關鍵互動規範：

#### A. 左側導覽列折疊 (Collapsible Sidebar)
- **點按項目自動收折**：點擊任一主視圖導覽項目（出單結帳、商品庫存、客戶會員）後，側邊欄**自動平滑收折**為緊湊圖示模式（64px 僅顯示 Icon 與 Tooltip），最大化作業區可用空間。
- 亦可點擊側邊欄底部 `[◀ 收折選單]` / `[▶]` 手動切換。

#### B. 字體清晰度規範 (Typography Standards - 16px+)
- POS 終端與收銀檯環境必須維持高易讀性，主要字體大小**維持 16px (`text-base`) 以上**。

#### C. 貨號、品名檢索與廠牌過濾 (Brand Tabs & Autocomplete)
- 輸入框支援熱鍵 `F2` 或 `/` 立即聚焦。
- **支援一鍵清空輸入框**：輸入關鍵字時右側出現圓形 `✕` 按鈕，點擊立即清空。
- 支援貨號去 dash 模糊比對（如輸入 `AA79121` 精準比對出 `AA-79121`）。
- 快捷過濾改用**模型廠牌（Brand Tabs）**（全部、AutoArt、Spark、Inno64、Mini GT、TLV、Kyosho 等）。

#### D. 表格式商品速查與商品詳情彈窗 (Product Result Table & Detail Modal)
- 左欄商品清單採高密度表格呈現（廠牌、貨號 SKU、車型品名、門市現貨、倉庫存量、定價、詳情按鈕）。
- **固定表頭 (Sticky Header)**：表格向下滾動時，表頭 (`<thead>`) 始終凍結固定在頂部，欄位標題與背景不跑位。
- **門市現貨獨立呈現**：門市現貨欄位如實顯示門市架上數量。若門市現貨為 0，顯示琥珀色「需調撥 (0)」，提示收銀員售出時可自倉庫調撥。
- **點擊整列直接加入**：點擊表格中該商品的任一欄位即可直接加入右側購物車，無需多餘的「+ 加入」按鈕。
- **「ℹ 詳情」按鈕與庫存分佈展示**：每列右側呈現按鍵大小適中、字體清晰的 `[ℹ 詳情]` 按鈕，點擊彈出「商品詳細資訊」彈窗（`ProductDetailModal`），展示：
  - 廠牌、比例、販售狀態
  - SKU 貨號、條碼 (Barcode)、原廠車色、車身材質
  - 門市牌價、會員 VIP 特價
  - 多據點庫存分佈（門市現貨、後方倉庫、公司總倉、全域總庫存、**「★ 預購未取」置於全域總庫存之後以 2xl 大字體呈現**）
  - **預購保留扣減規則**：**「★ 預購未取」配額扣減在「全域總現貨 (Total Stock)」**。提示框精簡設計：
    - **可售存量足夠時**：採低調內斂的灰黑底色無色強調 (`預購保留 X 台（可直接現售：Y 台）`)，不干擾視覺。
    - **可售總量不足或為負數時**：才以琥珀色警示醒目標示 (`⚠️ 預購保留 X 台（現貨不足以完全保留，尚缺 Z 台）[需進貨補足]`)。
  - **彈窗操作按鈕依進入路徑情境切換**：
    - **自待選商品清單（Product Table）點開**：提供 `[關閉]` 與 `[+ 加入此商品至結帳單]`，方便查詢後一鍵入單。
    - **自購物車清單（Cart Row）或出單二次確認彈窗點開**：該商品早已在結帳單內，因此**僅顯示 `[關閉]` 按鈕**，避免店員重複加入造成誤操作。
- 門市現貨不足（0 台）醒目標註琥珀色「需調撥」。

#### E. 當前結帳單精簡化與 Inline 即時編輯 (含總現貨預購保留檢查與非阻擋式現貨警示)
- **點擊購物車品項品名/貨號**：直接彈出「商品詳細資訊」彈窗（`ProductDetailModal`），方便收銀員隨時複查車型規格、原廠材質、條碼、各據點庫存與預購保留數量。
- 移除多餘的改價彈窗與「+/- 按鈕」，直接在購物車列表中的輸入框修改：
  - **單價 Inline 編輯**：點擊單價輸入框鍵入新價格，Enter 或失焦自動套用。若與原牌價不同，外框標註琥珀色並於下方呈現原價刪除線，自動重算折讓。
  - **數量 Inline 編輯與庫存警示即時更新**：點擊數量輸入框鍵入數量或透過上下鍵微調，小計、費用總計以及**紅黃色現貨不足 / 全域庫存不足警示皆同步即時連動更新**（無須等待失焦或按 Enter，輸入當下即刻依最新數值重新計算並切換警示狀態）。
  - **結帳數量庫存警示 (Overstock Alert - 獨立分行排版，絕不擠壓品名)**：
    - **單行排版與簡潔文案**：警示徽章獨立置於品名下方單獨一行（`whitespace-nowrap`），不分兩欄、不換行折行，直觀易讀：
      - 若購買數量大於門市現貨：顯示琥珀色徽章 `⚠️ 門市現貨不足（門市僅 X 台，需調撥）`。
      - 若購買數量大於全域可售總量：顯示紅色徽章 `⚠️ 全域庫存不足（總可售僅 Y 台）`。
    - 若修改數量調低至在庫數量以內：**紅黃色警示標籤立即自動消失**。
    - **非阻擋式結帳與出單二次確認 (Overstock Double-Confirmation)**：
      - 現貨不足時不阻擋收銀操作，但在按下「確認結帳出單」時，若清單中含有超出門市現貨或超出全域可售庫存的品項，**系統主動跳出獨立二次確認視窗**，列出品項、目前結帳數量與可售數量，要求收銀員點選「確認出單 (後續調撥)」後方才完成扣款出單。
  - **刪除按鈕**：點擊右側 `✕` 立即移除。

#### F. 運費自訂與快捷面額鍵
- 於商品小計與應收總計之間提供運費調整欄位。
- 提供 `[免運 $0]`、`[超商 $60]`、`[宅配 $100]` 常用快捷面額按鈕，並支援自訂金額輸入，即時累計至應收總計。

#### G. 會員即時自動下拉查詢與預訂單整合 (Instant Dropdown & PreOrder Detection)
- 右欄頂部會員輸入框支援**即時輸入即刻彈出下拉選單**（不需額外按查詢按鈕或按 Enter）。
- **支援一鍵清空**：輸入框內建 `✕` 快速清空按鈕。
- 輸入電話或姓名即展開即時比對清單（顯示姓名、電話、VIP 級別、點數），點選即可立即綁定。
- 綁定後：
  1. 購物車內有 VIP 優惠價之品項自動調降單價。
  2. 自動檢索該客人的未結預購單，若有**可提貨品項（`qtyArrived > qtyDelivered`）**，卡片下方立即展開待提貨明細。
  3. 店員點擊 **`+ 帶入結帳`** 即可直接將預購品項與報價加入購物車，標註藍色 `[預購取貨]` 徽章。

#### H. 「付款與收銀 (Payment Modal)」結帳彈窗與電子收據預覽
- 點擊「前往結帳付款」開啟彈窗（全面維持 16px 以上大字體，兼顧低解析度螢幕）：
  - **低解析度與螢幕高度自適應 (Low-res Viewport Safe)**：彈窗容器具備 `max-h-[90vh]` 與內部獨立滾動條，整體垂直 Padding 與 Gap 精簡收斂，找零與不足警示整合於輸入列上方即時顯示，確保在 768p / 800p 等門市小型螢幕或 POS 整合螢幕上完整顯示，絕不超出視窗或被遮擋截斷。
  - **應收總金額**：4xl 大字體高亮顯示（含運費與折讓）。
  - **支付方式切換**：`[現金]`、`[信用卡]`、`[LINE Pay]`、`[銀行轉帳]`，支援組合支付。
  - **實收現金輸入**：2xl 大字體等寬輸入框，**支援輸入即顯示右側一鍵清空按鈕 (`✕`)**，方便快速重鍵。
  - **現金快捷面額鍵 (由大到小排序)**：
     - 進位與剛好按鈕：`[進位千元]`、`[進位百元]`、`[剛好 $X,XXX]`。
     - 快速加總按鈕（降序）：`[+1000]`、`[+500]`、`[+100]`、`[+50]`、`[+10]`、`[+5]`、`[+1]`。
     - 即時計算找零：若實收大於應收，大字體顯示 **「應找零：NT$ XXX」**（綠色大字）；若不足則顯示 **「現金不足：尚缺 NT$ XXX」**（紅色大字）。
  - **可售庫存不足二次確認 (Overstock Double-Confirmation - 精簡版面與即時詳情)**：按下「確認結帳出單」若有品項超出門市現貨或全域可售庫存，即時彈出精簡緊湊之二次確認對話框（移除大塊警示卡片與贅字）：
    - **點選商品查看詳情**：清單中各列商品均具備點擊互動效果（附帶 `ℹ 詳情` 提示），店員點選任一品項即可**直接疊加開啟「商品詳細資訊」彈窗（`ProductDetailModal`）**，隨時複查車型規格、條碼、各據點庫存分佈與備註。
    - **品名與本次結帳數量**：單行高密度展示（品名 + 結帳數量徽章）。
    - **對稱雙欄庫存數據**：
      - 左側：`門市: X 台（需調撥 Y 台）`（琥珀色提示）
      - 右側：`總存: Z 台 · 預訂: W 台（須補貨 N 台）`（紅色提示）
    - 點選「確認出單 (後續調撥/補貨)」後方才完成扣款出單。
  - **電子收據預覽 (Receipt Preview)**：
    - **品名與數量獨立分欄**：品名（左側截斷保護）、數量（獨立欄位如 `x2`）、小計（靠右固定等寬對齊），確保超長品名絕不會將數量擠出版面之外。
    - 包含 Fred's POS 抬頭、單號、時間、各品項金額、支付方式、找零明細與發票載具/統編。

## 3. 視圖二：商品及庫存 (Products & Stock Management)

提供模型車實體店日常最核心的庫存查詢、門市倉庫調撥、直接編輯各地點數量批量存檔、商品詳情與編輯模式，以及快速新商品建檔。

### 3.1 介面配置與關鍵規範
1. **字體清晰度與特大號數字規範 (Typography Standards - 20px font-mono font-bold)**：
   - 庫存列表表格之門市現貨、後方倉庫、公司總倉、調度暫存、預估總計、**預購未交**與門市定價數字均全面採用 **`20px (`text-xl font-mono font-bold`)`** 等寬大字體與高對比色彩（預購未交不附加「台」單位）。
   - **條碼與廠牌字體細節放大**：國際條碼採用 `14px (`text-sm font-mono`)` 呈現；廠牌徽章採用 `14px font-bold text-zinc-200`（顯著大於比例/材質等次要標籤）。
2. **頂部篩選與功能操作區 (支援進階庫存狀況過濾器)**：
   - **搜尋框**：關鍵字搜尋（貨號 / 條碼 / 車型 / 廠牌），**內建一鍵清空按鈕 (`✕`)**，有輸入文字時自動顯示，點擊即刻清空。
   - **庫存與預購狀況進階過濾器 (`StockFilterType`)**：於搜尋框右側提供條件下拉選單（包含 `預購未交 > 門市現貨`、`預購未交 > 預估總計`、`門市現貨低庫存 ≤ 2`、`倉庫低庫存 ≤ 2`、`門市缺貨 = 0`、`全區缺貨 = 0` 與 `有現貨 > 0`），可與關鍵字搜尋及廠牌 Tab 疊加篩選。
   - **廠牌標籤切換 (Brand Tabs)**：提供快捷廠牌過濾標籤（`全部品牌`、`AutoArt`、`Spark`、`Inno64`、`Mini GT`、`TLV`、`Kyosho`、`Tarmac Works` 等）。
   - **核心功能按鈕**：
     - `[📥 快速條碼進貨]`：開啟 `RestockModal` 彈窗。
     - `[➕ 建立新商品]`：開啟 `CreateProductModal` 彈窗。
